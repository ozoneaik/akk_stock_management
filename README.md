# ระบบจัดการสต็อกสินค้า - ออฟกิจเกษตร (WTP2021)

ระบบสต็อกสินค้าสำหรับร้านขายปุ๋ย ยากำจัดวัชพืช/ศัตรูพืช และอุปกรณ์การเกษตร
พัฒนาเป็นโปรแกรม Desktop ด้วย Python + Tkinter สำหรับใช้งานบน Windows

**ใช้ฐานข้อมูลเดียวน TiDB Cloud (MySQL-compatible)

## สิ่งที่ต้องมีก่อนติดตั้ง

- Python 3.9 ขึ้นไป (ดาวน์โหลดจาก https://www.python.org/downloads/ — ตอนติดตั้งบน Windows
  ให้ติ๊ก "tcl/tk and IDLE" ไว้ด้วย ซึ่งเป็นค่าเริ่มต้นอยู่แล้วในตัวติดตั้งของ Windows)
- ไฟล์ `.env` ที่มี `DATABASE_URL` ชี้ไปที่ฐานข้อมูล TiDB เดียวกับที่เว็บแอปใช้ (ขอจากผู้ดูแลระบบ
  ถ้ายังไม่มี ห้ามเผยแพร่ค่านี้ออกไปข้างนอกเด็ดขาด เพราะเป็นรหัสผ่านฐานข้อมูลจริง)

## วิธีติดตั้งและรันโปรแกรม

1. แตกไฟล์ zip นี้ไปยังโฟลเดอร์ที่ต้องการ
2. เปิด Command Prompt / PowerShell แล้วเข้าไปที่โฟลเดอร์โปรเจกต์:
   ```
   cd <project>
   ```
3. ติดตั้งไลบรารีที่จำเป็น:
   ```
   pip install -r requirements.txt
   ```
4. สร้างไฟล์ `.env` ที่ root ของโปรเจกต์ (ระดับเดียวกับ `main.py`) ใส่บรรทัดเดียว:
   ```
   DATABASE_URL=mysql://<user>:<password>@<host>:4000/<database>?sslaccept=strict
   ```
5. รันโปรแกรม:
   ```
   python main.py
   ```

## บัญชีผู้ใช้สำหรับทดสอบ

เข้าสู่ระบบด้วย **username + PIN 4 หลัก** (ไม่ใช่ password อีกต่อไป — เปลี่ยนตาม schema ที่ใช้ร่วมกับเว็บแอป
ซึ่งออกแบบมาให้กดบนหน้าจอสัมผัสสะดวก):

| Username | PIN  | บทบาท                         |
|----------|------|--------------------------------|
| admin    | 9999 | แอดมิน (เห็นทุกหน้ารวมถึงบันทึกกิจกรรม) |
| owner    | 1234 | เจ้าของร้าน/พ่อ (เหมือนแอดมินทุกอย่าง ยกเว้นมองไม่เห็นหน้า "บันทึกกิจกรรม") |

> ถ้าต้องการ seed ข้อมูลตัวอย่างใหม่ ต้องลบข้อมูลในตาราง `User` ของฐานข้อมูลให้ว่างก่อน
> (การ seed จะข้ามอัตโนมัติถ้ามีผู้ใช้อยู่แล้ว) แล้วรัน `python -m database.seed`

## ฟีเจอร์ที่มีให้แล้วในเวอร์ชันนี้

- เข้าสู่ระบบด้วย username + PIN 4 หลัก (ตรงกับ schema ที่ใช้ร่วมกับเว็บแอป)
- บทบาทผู้ใช้ 2 แบบ: **ADMIN** และ **OWNER** (owner เห็นทุกอย่างเหมือน admin
  ยกเว้นเมนู "จัดการผู้ใช้", "บันทึกกิจกรรม" และ "สำรองข้อมูล" ที่ถูกซ่อนไว้)
- เมนูนำทางทั้งหมดอยู่ใน navbar แถบบนสุดแถบเดียว (ไม่มี sidebar แยกต่างหากแล้ว)
- **Dashboard**: สรุปจำนวนสินค้าทั้งหมด, จำนวนสต็อกรวม, และรายการสินค้าที่เหลือน้อยกว่าเกณฑ์
  ดับเบิลคลิกแถวสินค้าเพื่อดูรายละเอียดแบบ popup ได้เช่นเดียวกับหน้ารายการสินค้า
- **รายการสินค้า**: ค้นหาด้วยรหัส/ชื่อ, แสดงตาราง, ดับเบิลคลิกหรือกดปุ่มเพื่อดูรายละเอียดแบบ popup
- **รายละเอียดสินค้า**: มีปุ่ม "ปรับสต็อกสินค้า" ให้เพิ่ม/ลดสต็อกได้ทันทีจากหน้านี้ รองรับเลือกหน่วย
  (หน่วยย่อย เช่น ขวด หรือหน่วยบรรจุ เช่น ลัง — ระบบแปลงเป็นหน่วยย่อยให้อัตโนมัติ)
- **เพิ่ม/ลดสต็อกสินค้า**: ค้นหาสินค้า → เลือกได้ทีละหลายรายการพร้อมกัน (กด Ctrl/Shift ค้างไว้) → เพิ่มเข้ารายการปรับสต็อก
  → ดับเบิลคลิกแต่ละรายการเพื่อกำหนดรูปแบบ(เพิ่ม/ลด)/หน่วย/จำนวน/เหตุผลของตัวเอง → บันทึกทั้งหมดในครั้งเดียว
  (รายการที่บันทึกไม่สำเร็จ เช่น ทำให้สต็อกติดลบ จะค้างอยู่ในรายการให้แก้ไขโดยไม่กระทบรายการอื่น)
- **จัดการผู้ใช้งาน** (admin เท่านั้น): เพิ่ม/แก้ไข/ลบบัญชีผู้ใช้ ตั้ง/เปลี่ยน PIN กำหนดบทบาท
  พร้อมกันไม่ให้ลบบัญชีตัวเอง และกันไม่ให้ระบบเหลือ admin 0 คน (การ "ลบ" เป็นแบบปิดใช้งาน
  ไม่ใช่ลบถาวร เพื่อรักษาประวัติการทำงานเดิมของผู้ใช้นั้นไว้)
- **สำรองข้อมูล** (admin เท่านั้น): export ข้อมูลปัจจุบันทั้งหมดเป็นไฟล์ JSON ไว้เก็บสำรอง/ตรวจสอบย้อนหลัง
  (ไม่มีฟีเจอร์กู้คืนแบบเขียนทับฐานข้อมูลอีกต่อไป เพราะฐานข้อมูลใช้ร่วมกับเว็บแอปที่อาจมีคนอื่นใช้งานพร้อมกัน
  ถ้าต้องการกู้คืนข้อมูลจริงๆ ให้ใช้ฟีเจอร์ Backup/PITR ในหน้าคอนโซลของ TiDB Cloud โดยตรง)
- **บันทึกกิจกรรม** (admin เท่านั้น): log ทุกการเพิ่ม/แก้ไข/ลบสินค้า, ปรับสต็อก, จัดการผู้ใช้งาน
  พร้อมชื่อผู้ใช้และเวลา (เห็นร่วมกับฝั่งเว็บแอปด้วย เพราะเป็นตารางเดียวกัน)
- เพิ่ม/แก้ไข/ลบสินค้า พร้อมรองรับ: หมวดหมู่ (พิมพ์เพิ่มเองได้), หน่วยนับย่อย+หน่วยบรรจุ+อัตราแปลง,
  ราคาหน้าร้าน พร้อมส่วนลด, รูปภาพสินค้า (ใส่เป็นลิงก์ URL — ไม่ใช่ไฟล์ในเครื่องอีกต่อไป เพราะข้อมูลต้อง
  แสดงผลได้ทั้งจาก Desktop และเว็บที่รันอยู่คนละเครื่อง)
  — popup ฟอร์มนี้เลื่อนด้วยล้อเมาส์/trackpad ได้โดยตรง ไม่ต้องลากแถบเลื่อนอย่างเดียว
- แสดงหน้าจอ "กำลังโหลด" ระหว่างดึงข้อมูล และใช้ popup แจ้งเตือน/ยืนยันการทำงานสำคัญ
- ใช้ฟอนต์ Tahoma ทั้งระบบสม่ำเสมอ รวมถึงกล่องแจ้งเตือน (messagebox) และ dropdown ต่างๆ ด้วย
  (ตั้งค่าฟอนต์ default ของ Tk ไว้ที่ `ui_helpers.apply_global_font`)
- ใช้ธีมสี/สไตล์เริ่มต้นของ Tkinter (ttk) โดยไม่ปรับแต่งเพิ่มเติม

## ฐานข้อมูลร่วมกับเว็บแอป

ใช้ **TiDB Cloud** (MySQL-compatible, serverless) เป็นฐานข้อมูล
schema ถูกสร้าง/จัดการผ่านฝั่ง Desktop นี้เชื่อมต่อผ่าน `PyMySQL` เท่านั้น

ผลที่ตามมาจากการใช้ฐานข้อมูลร่วม:
- **id เป็น string (UUID)** ไม่ใช่เลขรันอัตโนมัติแบบเดิม
- **role เก็บเป็นตัวพิมพ์ใหญ่** (`ADMIN`/`OWNER`) และ **login ด้วย PIN แทน password**
- การ "ลบ" ผู้ใช้/สินค้าเป็นแบบ soft-delete (`isActive = FALSE`) เสมอ เพราะมีตารางอื่นอ้างอิง
  (StockMovement, ActivityLog) แบบ `ON DELETE RESTRICT` การลบจริงจะทำให้เกิด error ถ้าเคยมีประวัติ
- รูปภาพสินค้า/ผู้ใช้เก็บเป็น **ลิงก์ URL** เท่านั้น

## แผนสำหรับโมดูลในอนาคต (ยังไม่ได้ทำในเวอร์ชันนี้)

- Sync สต็อกสินค้ากับ Shopee, Lazada, TikTok (ตาราง `ChannelStockMapping` มีอยู่แล้วในฐานข้อมูล
  แต่ยังไม่มีหน้าจอใช้งานทั้งฝั่ง Desktop และเว็บ)
- ระบบตอบแชทรวมทุกแพลตฟอร์มในที่เดียว (ตาราง `ChatConversation`/`ChatMessage` มีอยู่แล้วเช่นกัน)
- อัปโหลดรูปภาพจากเครื่องโดยตรง (ตอนนี้ต้องมีลิงก์ URL ของรูปอยู่แล้วเท่านั้น)

โครงสร้างโค้ดปัจจุบัน (แยก models/controllers ออกจากฐานข้อมูลโดยตรง) ถูกออกแบบมาให้ต่อยอด
เพิ่มโมดูลเหล่านี้ในอนาคตได้โดยไม่ต้องรื้อโครงสร้างเดิม
